# Security

This repository is Markdown and two small Python scripts that read files in the repository and write two files back into it. Nothing here runs code on your machine when installed as a skill; the agent reads the text and follows it.

If you find something that contradicts that, open an issue or email the maintainer through the address on the GitHub profile. Please do not file security reports for the content of quotations; those go under the "A quote is wrong" issue template.
